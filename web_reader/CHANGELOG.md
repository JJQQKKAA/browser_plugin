# 更新日志

所有版本的变更记录。

## [Unreleased]

### 新增
- Thinking 增加首次回答和后续追问两个开关，自动模式默认首轮关闭、第二轮及以后开启，重试按原轮次处理
- 更新内置快速摘要为精简模板，减少逐章复述及冗长细节，已有任务内容保持不变
- 默认提供快速摘要、详细解读、翻译三个阅读任务；支持自定义按钮数量、隐藏及排序，保留已有 Prompt
- 支持停止生成并保留部分结果，以及基于本轮原始输入重新生成
- 每个模型可配置 Thinking 模式，ModelScope 默认发送 `enable_thinking: false`
- 添加 SSE、任务迁移、请求参数回归测试及模拟 API 的浏览器流程测试

### 改进
- 配置统一为模型与阅读任务，移除旧默认组合和标签，保留原有内容及上次选择
- 任务列表支持直接切换首页显示、拖拽及键盘排序；复制和删除收进更多菜单，删除可撤销
- 新建任务和内置模板入口分离，任务指令作为主要编辑区，System Prompt 收进高级设置，保存后即时反馈
- 模板改为用户主动添加，不再自动追加或覆盖保存的任务；新导出格式兼容读取旧版配置
- 快速摘要以简明说清事情为目标，取消固定字数、要点数量与三段式结构；内置模板由用户主动添加，保留已有自定义提示词
- 统一输入、输出、合计 Token 显示，默认请求流式 usage；逐项标记估算，补充缓存与思考明细，正确处理零值、重复快照、停止及重试累计
- 优先保证正文阅读空间：生成及恢复后自动收起任务区，任务浮层不挤占正文，合并状态与操作栏，首轮完成回到正文开头
- 全面统一弹窗及设置页视觉、字号、留白和控件，支持跟随系统的深色模式
- 长对话独立滚动，输入区固定，支持回到最新内容
- 显示当前模型及提示词摘要，任务管理可直接跳转到对应设置

### 修复
- 替换手写 Markdown 解析器为本地官方 Marked 17.0.5，修复列表后段落被错误包入列表导致缩进、嵌套列表结构错误及代码缩进丢失
- 移除自动补引用缩进，区分列表内引用与顶格独立引用；新增 Markdown 结构及浏览器对齐回归验证
- SSE 解析保留跨分块的半行与 UTF-8 字符，处理 CRLF、结束标记及流末尾事件，避免静默丢失内容
- 修复列表项内嵌子列表后紧跟引用块时，外层有序列表被截断、编号重置的问题
