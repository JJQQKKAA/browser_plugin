# Web Reader - AI 网页总结插件

[![版本](https://img.shields.io/badge/version-1.2.0-blue.svg)](#更新日志)

使用自定义 AI 模型总结网页内容，支持多模型配置和多轮对话。

## 功能特点

- 🔧 **灵活配置**: 支持任意 OpenAI 兼容格式的 API
- 💾 **本地存储**: 配置和 Prompt 保存在本地，保护隐私
- 🤖 **自定义 Prompt**: 可配置 System Prompt 和 User Prompt
- ⚡ **流式响应**: 实时显示 AI 生成的总结内容
- 💬 **多轮对话**: 总结后可继续提问，保持对话上下文
- 🎨 **Markdown 渲染**: 支持渲染 AI 返回的 Markdown 格式内容
- 📌 **状态保持**: 切换标签页后总结结果不会丢失
- 📤 **配置导入/导出**: 支持 JSON 格式的配置备份和迁移

## 安装方法

1. 准备图标文件（icon16.png、icon48.png、icon128.png），可用 `icon-generator.html` 生成
2. 打开 Chrome/Edge 浏览器（Chrome 内核 151 或以上），进入 `chrome://extensions/`
3. 开启「开发者模式」，点击「加载已解压的扩展程序」
4. 选择 `web_reader` 文件夹

## 配置 API

1. 右键点击扩展图标，选择「选项」
2. **模型配置**: 添加模型（名称、API URL、API Key、模型代码、Temperature）
3. **阅读任务**：新建任务，填写名称和任务指令；需要额外角色约束时展开「高级设置」
   - 任务指令中使用 `{{content}}` 插入网页正文

## 使用方法

1. 打开任意网页，点击 Web Reader 图标
2. 选择模型和 Prompt
3. 点击「快速摘要」「详细解读」或「翻译」任务按钮，也可展开配置后运行自己的提示词
4. 可继续提问进行多轮对话

## 阅读任务与生成控制

- 默认提供「快速摘要、详细解读、翻译」三个按钮；翻译任务默认将外文译为中文、中文译为英文。
- 点击首页「管理任务」，新建或编辑任务；卡片上的「首页显示」开关可直接控制首页按钮，关闭后仍可在任务列表中运行。
- 拖动任务左侧手柄排序，也可选中手柄后按 ↑ / ↓，或使用「更多」里的上移、下移；顺序同步用于首页和任务下拉列表。
- 「从内置模板添加」提供快速摘要、详细解读、翻译，选中后可继续修改，保存为独立任务。快速摘要采用精简模板，只讲主旨、结论和不可省略的依据，不逐章复述。模板不会自动覆盖已有任务；需要新版指令时可从模板添加。
- 模型和任务的「更多」菜单提供复制、删除，删除后有 12 秒可撤销。保存、排序、开关操作都有即时反馈。
- 移除旧的默认组合与默认标签；弹窗记住上次选择的模型和任务，首次使用或已选项目被删除时选择列表第一项。升级保留现有模型与任务内容，导入旧版文件也不再生成组合或额外补充模板。
- 生成时可点击「停止生成」，保留已输出内容；「重新生成」使用本轮原始输入重试，替换本轮回答，不会重复追加提问。
- 重新生成使用上次请求的模型；要切换模型，请选择模型后重新运行阅读任务。
- 开始生成或恢复结果后自动进入阅读模式，收起页面详情、模型配置和任务按钮；顶部标题行或下拉按钮可展开任务浮层，浮层不压缩正文，点击外部或按 Esc 收起。
- 首轮完成后从正文开头阅读；长对话只滚动消息区域，输入框固定在底部，向上阅读时不强制跳到底部，可点击「回到最新」。
- 界面自动跟随系统浅色 / 深色主题。

## 网页划词助手

1. 在普通 HTTP/HTTPS 网页选中单词或一段文字，选区旁会出现 28×28 的小书本图标。
2. 点击图标打开卡片。顶部一行可切换任务、运行/停止、复制和关闭；模型、原文与设置收进右上角调节菜单，正文区域独立滚动。
3. 任务复用设置页里的全部 Prompt（包括未在首页显示的任务），可以翻译、快速摘要、详细解读或运行自定义指令；暂无任务时临时提供三个内置模板。
4. 卡片单独记住上次运行的任务，首次使用参考弹窗上次任务，再回退到列表第一项。模型默认使用弹窗上次选择，可临时切换；不改变弹窗的模型或任务偏好。
5. 支持停止、重新生成和复制。切换任务/模型会停止旧请求，等待再次点击运行。点击外部、关闭按钮或按 Esc 关闭时取消请求；滚动只隐藏图标，不关闭卡片。

在扩展设置 →「划词助手」→「默认操作」中，可选择「仅打开处理框，不自动生成」（默认），或直接运行任一已有任务，例如翻译或摘要；即时保存，下次点击图标生效。默认任务被删除时只打开处理框。此偏好独立保存在本机，不包含在模型/任务配置导出中。

选中文字只在本地用于显示入口；手动模式点击运行、自动模式点击划词图标后，才将选区及任务指令发送到所选模型。`{{content}}` 替换为选区，没有占位符时会在指令末尾附加选区。结果按纯文本显示，不持久保存，不改写总结会话或计入其 Token 累计。输入框和可编辑区域不显示入口，单次最多 12000 字符，请求最多等待两分钟。

普通网页入口支持主文档，不支持 Chrome 内部页面及 iframe 内选区；PDF 请使用下面的 Web Reader PDF 阅读器。更新扩展后请刷新已打开的网页，以加载新的划词脚本。

## PDF 阅读与划词

- 点击扩展顶部的 PDF 图标，或在「扩展设置 → PDF」中打开阅读器。常见 `.pdf` 地址会由弹窗入口带入；也可以选择本地文件、拖入文件，或填写在线 PDF 地址。
- 在「扩展设置 → PDF」开启「自动用 Web Reader 打开 PDF」，之后在线及本地 PDF 都会自动进入阅读器；关闭后由浏览器处理，仍可手动打开。默认关闭，即时保存，属于本机偏好，不随模型/任务配置导出。
- 自动接管采用 Chrome 151+ 的原生 `mimeHandler`，按 `application/pdf` 类型处理顶层文档，不依赖 URL 后缀。本地自动接管及手动选择文件均无需开启「允许访问文件网址」。未实现该 API 的浏览器只能手动打开阅读器。
- 阅读器支持连续滚动、页码跳转、缩放、文档搜索（Ctrl / ⌘ + F）。支持双击选词、连续重选、正反向及跨页拖选；从行首或段间空白起选时按最近文字定位，拖到视口外可滚动扩选，松手后才显示划词图标。
- 高亮按 PDF 的文字基线和实际字体字形绘制，贴合粗体标题及不同字号，避免选中框过高或偏到文字下方；旋转/竖排文字、Type3 字体或无法匹配的文字层保留浏览器原生高亮。选中文字后，沿用现有划词图标、任务、模型和默认事件；仅执行任务时将选区与指令发送给模型，不上传整份 PDF。
- 更新扩展后，请关闭并重新打开已有 PDF，以加载新的阅读器代码。
- 预编译 PDF.js 6.4.299 连同 Worker、文字层、字体和图像资源均本地打包，无 CDN 或运行时安装，许可证见 `vendor/pdfjs/LICENSE`。
- 首期只处理文字型 PDF 选区，不做扫描件 OCR 或整份 PDF 总结；密码保护的文件需先解密。网站嵌入的 PDF 不自动接管。
- 需登录、特殊鉴权的地址可能无法手动加载，可下载后选择本地文件。直接通过 `file://` 地址手动读取失败时，也可改用文件选择器。自动接管模式会消费浏览器已收到的原始响应，支持单次链接；「浏览器查看」回退可能重新请求原地址。

## ModelScope 与深度思考

模型编辑页提供两个独立开关：

- **首次回答使用 Thinking**：默认关闭，适用于点击阅读任务后的首次总结。
- **后续追问使用 Thinking**：默认开启，适用于第二轮及以后所有追问。
- 重新生成按原始请求的轮次处理，首轮重试仍是首轮，追问重试仍是追问；重新运行阅读任务会开始新的首轮。

兼容方式可选择：

- **自动识别（默认）**：仅对 ModelScope 域名发送顶层 `enable_thinking`，值由两个开关决定；其他服务不附加此参数。
- **发送 enable_thinking（兼容接口）**：对支持该参数的服务或代理发送分轮开关值。
- **跟随服务默认**：不发送此参数，开关禁用；适用于不能切换思考的模型或不支持该字段的服务。

已有配置中显式开启或关闭的旧设置会保留为两轮同值；未指定的自动模式采用首次关、追问开。直接使用 `fetch` 时参数放在请求 JSON 顶层，不嵌套在 `extra_body` 中。参见 [ModelScope 官方调用示例](https://community.modelscope.cn/6810a75dc89bb1649888b621.html)。

## Token 统计

每条回答底部统一显示「输入 120 · 输出 80 · 合计 200 Token」，累计数悬浮可查看输入、输出和合计明细；不额外增加常驻工具栏。

- 默认请求 `stream_options: { include_usage: true }`。每个模型的「请求流式 Token 统计」可独立关闭，兼容不接受此参数的接口。
- 适配现有 OpenAI 兼容接口：优先读取 `usage.prompt_tokens`、`completion_tokens`、`total_tokens`，兼容网关返回的 `input_tokens` / `output_tokens` 别名。这不意味着新增 Anthropic / Gemini 原生接口支持。
- 读取末尾无正文的 usage 分块；中途统计按本轮累计快照覆盖，不逐块相加。返回的 `0` 是有效值。
- 缺失字段才估算，数字前用 `≈` 标记；输入估算覆盖本轮发送的全部历史上下文。已知平台合计与一个分项时，另一分项由二者相减获得；仅返回合计时保留平台合计，缺失分项独立估算。
- 平台返回的缓存命中和思考 Token 在悬浮明细中展示，作为输入 / 输出的组成部分，不重复加到合计。
- 会话累计包括重试和收到响应后的中断请求；中断时只能估算已收到内容，可能缺少最终 usage，不代表平台最终账单。累计中含估算或来源不明的历史统计时同样标记 `≈`。
- ModelScope 的具体模型是否返回 usage 以实际响应为准，缺失时按上述规则估算。尚未使用真实账号逐个平台进行联调。

参考：[OpenAI 流式用量字段](https://developers.openai.com/api/reference/resources/chat/subresources/completions/streaming-events)、[百炼流式输出](https://help.aliyun.cn/zh/model-studio/stream)、[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[Kimi 官方兼容说明](https://forum.moonshot.ai/t/api-not-fully-openai-compatible/67/2)、[ModelScope 官方 EvalScope 的兼容请求与 usage 处理](https://github.com/modelscope/evalscope/blob/main/evalscope/perf/plugin/api/openai_api.py)。

## Markdown 排版

- 使用本地打包的官方 Marked 17.0.5（UMD，MIT 许可证见 `marked.LICENSE.md`），无需 CDN、构建步骤或额外安装运行依赖。
- 按原始 Markdown 的层级解析列表、引用和段落，不再自动给引用补缩进。列表结束后的结论段落保持顶格，子列表保留在父列表项中。
- 若引用属于列表项，请在原始 Markdown 中按该项正文的缩进书写；顶格的独立引用不会被自动吸入前面的列表。
- 围栏代码块（包括标注为 markdown 的代码示例）按代码显示，保留缩进和转义字符。
- Markdown 回归：`node --test tests/markdown.test.js`；运行全部核心测试：`node --test tests/*.test.js`。

## 开发验证

无需构建，依然可以直接加载扩展源码目录。

- PDF 真实拖选回归：`node tests/pdf-selection-browser.cjs`，覆盖高 DPI、连续重选、正反向/跨行/跨页、行首/段间空白、视口外滚动扩选、缩放、Shift 扩选与精确双击选词；在 100%/150% 缩放下对照画布真实文字像素验证紧行距单词、页下方粗体标题与混合字号的高亮边界，并验证搜索后的选区。使用真实鼠标，不用代码直接制造选区。
- PDF 真扩展回归：`node tests/pdf-browser.cjs`，需要 Chrome 151+、Playwright；在临时配置中真实加载扩展，模型服务由本地 HTTP 服务模拟，覆盖在线/本地、原生接管、选区、搜索/缩放、开关与回退。
- 划词助手浏览器回归：`node tests/selection-browser.cjs`，同样支持 `PLAYWRIGHT_MODULE_PATH`，使用真实划词界面和后台处理器、模拟模型服务。
- 核心回归测试：`node --test tests/reader-core.test.js`，覆盖 SSE 任意字节分块、中文解码、事件结束、任务迁移和 Thinking 参数。
- 浏览器回归：安装 Playwright 且本机有 Chrome 时运行 `node tests/browser-smoke.cjs`。也可用 `PLAYWRIGHT_MODULE_PATH` 指向已有 Playwright 模块。测试使用模拟 API，不会调用真实模型。

## Prompt 配置示例

**System Prompt:**
```
你是一个专业的网页内容总结助手，擅长提取文章的核心观点和关键信息。
```

**User Prompt:**
```
请总结以下网页内容：

{{content}}

请用中文输出，控制在 200 字以内。
```
