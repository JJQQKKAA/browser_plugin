# Web Reader 隐私政策

最后更新日期：2026-10-22

## 概述

Web Reader 是一款浏览器扩展，帮助用户使用自定义 AI 模型总结网页内容。我们高度重视用户隐私，本政策说明我们如何处理您的数据。

## 数据收集与使用

### 我们收集的信息

**本地存储的数据（仅保存在您的设备上）：**
- AI 模型配置信息（API URL、API Key、模型名称）
- 自定义 Prompt 配置
- 阅读任务的顺序、首页显示、划词默认任务及 PDF 自动接管偏好

**临时处理的数据：**
- 当前网页的文本内容（在您主动运行阅读任务时提取）
- 划词选区（在本地检测以显示按钮，仅在手动运行任务，或点击已配置自动执行任务的图标后发送所选文本；生成结果不持久保存）
- PDF 文件字节与文字层（在浏览器本地读取和渲染，不发送整个文件到模型；执行划词任务时仅发送选区）
- 对话历史记录（临时保存在浏览器本地存储中，5分钟后自动过期）

### 数据处理方式

1. **网页内容提取**
   - 仅在您主动运行阅读任务时，提取整页正文；划词入口只在本地检测选中文字
   - 内容脚本未加载时的备用提取路径最多保留约 15000 字符，其他提取路径不保证此上限
   - 划词助手仅发送所选文字及所选任务指令，不发送整页正文；单次最多 12000 字符
   - PDF 阅读器本地处理文件，在线模式读取原站点或浏览器已接收的响应；划词仅发送选区和任务指令，不上传整份 PDF
   - 阅读任务内容仅发送到您配置的 AI API 进行处理

2. **AI API 通信**
   - 所有 AI 请求直接发送到**用户自行配置的 API 端点**
   - 我们不会将任何数据发送到我们自己的服务器
   - 请求使用您配置的地址；HTTPS 端点使用加密传输，本地模型也可配置 HTTP 地址

3. **数据存储**
   - 所有配置数据使用 Chrome Storage API 本地存储
   - 配置不会作为备份上传远程服务器；模型请求会将 API Key 用作认证凭据发送给您配置的端点
   - 卸载扩展后，所有本地数据将被浏览器自动清除

## 我们不收集的数据

- 不收集个人身份信息
- 不收集浏览历史记录
- 不收集用户习惯数据
- 不使用追踪 Cookie
- 不向第三方出售或分享任何数据

## 权限说明

扩展请求以下权限，仅用于实现核心功能：

| 权限 | 用途 |
|------|------|
| `activeTab` | 获取当前标签页信息，用于提取网页内容 |
| `storage` | 本地存储用户的模型和 Prompt 配置 |
| `scripting` | 注入内容脚本以提取网页文本 |
| `windows` | 打开独立阅读窗口 |
| `http://*/` 和 `https://*/` | 网页正文提取、划词入口及向用户配置的 AI API 发送请求 |

PDF 自动接管通过 Chrome 151+ 的原生 MIME 接口实现，默认关闭，可在设置页关闭；不增加 file:// 主机权限。Wasm 仅用于本地打包的 PDF.js 解码资源。

## 用户责任

使用本扩展时，您需要：
- 确保您配置的 AI API 服务符合其自身的隐私政策
- 妥善保管您的 API Key，避免泄露给他人
- 了解并遵守您使用的 AI 服务的使用条款

## 数据安全

- 所有 API Key 仅存储在本地浏览器中
- 使用 `chrome.storage.local` 存储配置，未额外加密；导出配置包含 API Key
- 扩展代码开源，可审计数据处理逻辑

如有隐私政策的重大变更，我们将在扩展更新时通知用户。

您可以随时：
