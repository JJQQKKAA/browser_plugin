# Web Reader 隐私政策

最后更新日期：2026-02-26

## 概述

Web Reader 是一款浏览器扩展，帮助用户使用自定义 AI 模型总结网页内容。我们高度重视用户隐私，本政策说明我们如何处理您的数据。

## 数据收集与使用

### 我们收集的信息

**本地存储的数据（仅保存在您的设备上）：**
- AI 模型配置信息（API URL、API Key、模型名称）
- 自定义 Prompt 配置
- 模型与 Prompt 的组合配置

**临时处理的数据：**
- 当前网页的文本内容（仅在您主动点击"总结"按钮时提取）
- 对话历史记录（临时保存在浏览器本地存储中，5分钟后自动过期）

### 数据处理方式

1. **网页内容提取**
   - 仅在您主动触发总结功能时，提取当前网页的可见文本内容
   - 提取的内容会被截取至约 15000 字符以内
   - 内容仅用于发送到您配置的 AI API 进行处理

2. **AI API 通信**
   - 所有 AI 请求直接发送到**用户自行配置的 API 端点**
   - 我们不会将任何数据发送到我们自己的服务器
   - API 通信使用标准的 HTTPS 加密传输

3. **数据存储**
   - 所有配置数据使用 Chrome Storage API 本地存储
   - 数据不会上传到任何远程服务器
   - 卸载扩展后，所有本地数据将被浏览器自动清除

## 我们不收集的数据

- 不收集个人身份信息
- 不收集浏览历史记录
- 不收集用户习惯数据
- 不使用追踪 Cookie
- 不向第三方出售或分享任何数据

## 权限说明

扩展请求以下权限，仅用于实现核心功能：

| 权限 | 用途 |
|------|------|
| `activeTab` | 获取当前标签页信息，用于提取网页内容 |
| `storage` | 本地存储用户的模型和 Prompt 配置 |
| `scripting` | 注入内容脚本以提取网页文本 |
| `http://*/` 和 `https://*/` | 允许向用户配置的 AI API 发送请求 |

## 用户责任

使用本扩展时，您需要：
- 确保您配置的 AI API 服务符合其自身的隐私政策
- 妥善保管您的 API Key，避免泄露给他人
- 了解并遵守您使用的 AI 服务的使用条款

## 数据安全

- 所有 API Key 仅存储在本地浏览器中
- 使用 Chrome 的加密存储机制保护敏感配置
- 扩展代码开源，可审计数据处理逻辑

## 政策更新

如有隐私政策的重大变更，我们将在扩展更新时通知用户。

## 权限撤销

您可以随时：
1. 在扩展选项页面删除所有配置数据
2. 通过浏览器扩展管理页面卸载扩展，清除所有本地数据
